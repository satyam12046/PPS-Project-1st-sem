# 🍽️ Restaurant Manager Project

A console/application-based **Restaurant Management System** developed as part of the 1st-semester Programming for Problem Solving (PPS) project. This project helps automate and streamline daily restaurant operations such as taking orders, managing menus, calculating bills, and handling table reservations.

---

## 🚀 Features

* **Menu Management:** View available food items categorized by starters, main courses, beverages, and desserts, along with their prices.
* **Order Placement:** Take customer orders interactively by selecting item numbers and quantities.
* **Billing System:** Generate an itemized bill with subtotal, taxes, and discounts automatically calculated.
* **Table Reservation (Optional/Extended):** Check table availability and book tables for customers.
* **User-Friendly Interface:** Clean, menu-driven command-line interface for easy navigation.
